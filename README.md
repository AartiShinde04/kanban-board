# 📋 Kanban Task Management Board

A responsive and interactive Kanban Task Management Board built using **HTML, CSS, and JavaScript**.

The application allows users to create, organize, search, filter, edit, and delete tasks using a simple drag-and-drop workflow.

## 🚀 Live Demo

👉 [View Live Project](https://aartishinde04.github.io/kanban-board/)

---

## ✨ Features

### 📌 Task Management
- Create new tasks
- Edit existing tasks
- Delete tasks
- Add task descriptions
- Set task priority
- Set task due dates

### 🔄 Drag and Drop
Tasks can be moved between:

- 📝 To Do
- ⚡ In Progress
- ✅ Done

The task status is automatically updated when a task is moved.

### 🔎 Search & Filtering
- Search tasks by title or description
- Filter tasks by priority
- Filter tasks by status
- Clear all filters

### 📊 Dashboard
The dashboard displays:

- Total Tasks
- To Do Tasks
- In Progress Tasks
- Completed Tasks
- Overdue Tasks

### 📅 Due Date Tracking
Tasks display their current deadline status:

- ✓ On Track
- ● Due Soon
- ⚠ Due Today
- ⚠ Overdue
- ✓ Completed

### 🌙 Dark Mode
Users can switch between light and dark mode.

The selected theme is saved and remains active when the page is reopened.

### 💾 Local Storage
Tasks are stored using the browser's **LocalStorage**, so task data remains available after refreshing or reopening the website.

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive layout
- **JavaScript (ES6)** – Application logic and interactivity
- **HTML5 Drag and Drop API** – Moving tasks between columns
- **LocalStorage API** – Persisting tasks and theme preferences
- **Git & GitHub** – Version control
- **GitHub Pages** – Deployment
